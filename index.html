Modulo de Escenarios

En Chrome o Edge se abrira el dialogo nativo para elegir la carpeta de guardado. En otros navegadores se usara la descarga estandar.
"Enviar por WhatsApp" envia un resumen de texto. "Enviar Propuesta (.html)" adjunta el documento como archivo real usando el panel de Compartir del sistema (funciona en Chrome/Edge Android y navegadores compatibles); si el navegador no lo soporta, se descarga el archivo automaticamente para que lo adjuntes manualmente.
"Importar Cotizacion (.html)" carga un archivo previamente exportado con esta herramienta. Si el archivo se genero con "Exportar como HTML" (o "Exportar" desde el Historial), se recuperan TODOS los datos internos (Cant., Compra USD, Mejor Proveedor, Tipo de Cambio, Margen Comercial %, Flete S/. y M.O. S/.), listos para seguir editando. Si en cambio el archivo se genero con "Enviar Propuesta (.html) por WhatsApp" (el que va al cliente), esos costos internos nunca viajan en el archivo y solo se recupera el Precio Unitario ya calculado.

Cotizacion por Alternativas / Opciones Comparativas

Cada alternativa se calcula de forma independiente (no se suman entre si). Usa el Tipo de Cambio (T.C.) de Parametros Globales para la conversion a USD. La Comision % se descuenta de la utilidad neta del vendedor, no afecta el precio final al cliente.
